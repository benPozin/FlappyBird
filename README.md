# Flappy Bird Clone (Java)

A simple Flappy Bird clone built in Java Swing. Fly the bird through the gaps between pipes and rack up the highest score.

## Technologies
- **Java** - Main programming language  
- **Java Swing** - Used for rendering graphics and handling UI  

## Prerequisites
- Java Development Kit (JDK) 11 or higher
- Git (for cloning the repository)

## Features
- Bird movement using spacebar
- Randomly generated pipes
- Score tracking system
- Collision detection (Game Over when you hit a pipe)
- Restart the game with 'R'

## How to Run
1. **Ensure Java is installed**:
   Verify with `java --version`

2. **Clone the repository**:
   ```
   git clone https://github.com/benPozin/FlappyBird.git
   ```

3. **Navigate into the project folder**:
   ```
   cd FlappyBird
   ```

4. **Open the project** in IntelliJ, Eclipse, or VS Code.

5. **Compile and run** `FlappyBird.java`.

## Controls
- **SPACE** - Make the bird jump  
- **R** - Restart after Game Over
